# 👁 눈으로 (with-eyes)

**눈을 위로 올렸다 내리는 동작 하나만으로 한국어 문장을 만들고 음성으로 말하는 의사소통(AAC) 웹앱**

전신마비(감금증후군 등)로 눈을 위로 움직이는 것만 가능한 분을 위해 만들었습니다.
아래를 볼 수 없어도 됩니다 — 단일 스위치 스캐닝 방식이라 "위 응시" 한 가지 동작이면 충분합니다.
웹캠 영상 분석, 단어 예측, 음성 합성까지 **모든 처리가 사용자의 기기 안에서만** 이루어지며,
서버로 어떤 데이터도 전송하지 않습니다.

## 작동 방식

| 단계 | 기술 |
| --- | --- |
| 시선 감지 | [MediaPipe FaceLandmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) (웹캠, 브라우저 내 추론) — 홍채 중심↔눈꼬리선 수직거리(머리 기울기 불변) + 시선 블렌드셰이프를 사용자별 보정(가운데/위 2지점)으로 융합, "위 응시" 제스처 하나를 스위치처럼 감지 |
| 글자 선택 | 화면을 위/아래 두 밴드로 나누고 **하이라이트가 자동으로 번갈아 켜지는** 단일 스위치 스캐닝. 원하는 글자가 있는 칸에 불이 켜졌을 때 위를 보면 그 칸이 절반으로 줄어드는 이분 탐색. 한글 빈도 가중치로 자주 쓰는 글자일수록 적은 응답으로 도달 |
| 한글 조합 | 2벌식 IME 방식 자모 오토마타 (겹모음·겹받침·연음 분리·자모 단위 지우기) |
| 단어 추천 | 완전 로컬 통계 언어 모델 — 자모 접두사 트라이 + 빈도 사전 + **사용자 어휘/바이그램 학습**(localStorage) + 받침 규칙 기반 조사 추천 |
| 음성 출력 | Web Speech API 한국어 음성 (기기 내장 음성 우선) |

### 입력 규칙 (환자용)

- 파란-초록 불이 위/아래 칸을 번갈아 켜집니다. **원하는 칸에 불이 켜졌을 때 위를 보면**(0.7초 유지) 그 칸이 선택됩니다
- 시선을 올리기 시작하면 불 전환이 멈추므로, 보던 칸이 그대로 선택됩니다
- 선택 직후 **계속 위를 응시**(약 1.8초)하면 방금 선택 **취소**
- **두 눈을 3초 감으면 쉬기** — 재개는 위 응시 3번 연속 (보호자는 버튼으로 바로 재개 가능)
- 얼굴이 카메라에서 사라지면 입력이 자동으로 멈춥니다

### 화면 구성

- 위 밴드: **추천 단어**(초록), 빠른 말·말하기·띄어쓰기·지우기 등 **명령**(파랑)
- 아래 밴드: **자모판** — 오토마타 상태에 맞춰 자음/모음이 자동으로 얕은 위치에 배치
- 긴급/고빈도 문장은 **빠른 말**에서 몇 번의 응답만으로 바로 말할 수 있습니다
  (아파요 · 숨이 답답해요 · 석션 해주세요 · 화장실 가고 싶어요 …)

## 실행 방법

빌드 과정이 없는 정적 웹앱입니다. **웹캠 접근을 위해 `localhost` 또는 HTTPS가 필요**합니다.

### 모바일 / 다른 기기에서 (GitHub Pages)

푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다:

**https://choisian.github.io/with-eyes/**

휴대폰/태블릿 브라우저(안드로이드 Chrome, iOS Safari)로 접속해 카메라 권한을 허용하면
바로 사용할 수 있습니다. 전면 카메라가 자동 선택되고, 사용 중에는 화면이 꺼지지 않습니다.
카메라 없이 눌러 보려면 **키보드·터치 테스트 모드**에서 화면을 짧게 탭(=위 응시),
길게 누르기(=되돌리기)로 조작하세요.

### 로컬에서

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 브라우저(Chrome/Edge 권장)에서 http://localhost:8000 접속
```

> 최초 실행 시 얼굴 인식 모델(약 3.7MB)을 CDN에서 내려받습니다. 이후 브라우저 캐시로 동작합니다.
> 카메라 없이 동작을 확인하려면 시작 화면의 **키보드 테스트 모드**(Space/↑ = 위 응시,
> Backspace = 되돌리기, P = 쉬기)를 사용하세요. (`?keyboard=1`을 주소에 붙이면 바로 시작)

## 보호자 가이드

### 카메라 설치 (가장 중요합니다)

- 얼굴 정면, **눈높이 또는 약간 위**, 40~60cm 거리 (침대 위 거치대/자바라 권장)
- 얼굴 **앞쪽에서** 빛이 비치게 (창문을 등지게 두지 마세요 — 역광이면 인식 불가)
- 환자 머리가 기울어 있으면 카메라/태블릿도 비슷하게 기울여 주세요
- 사용 중에는 보호자 얼굴이 화면에 들어가지 않게 해 주세요

### 보정과 연습

첫 사용과 자세/조명이 바뀔 때마다 **보정**(약 30초)을 해 주세요.
가운데→위 점을 두 번씩 바라보면 환자 개인의 시선 범위에 맞는 임계값이 만들어집니다.
보정 품질이 낮으면 앱이 시작을 거부하고 조정 방법을 안내합니다. 이어지는 **연습**에서
위 응시 4번 중 3번 이상 인식되고 오인식이 적어야 본 화면으로 넘어갑니다.
"사용할 눈" 설정을 바꾸면 기준선이 달라지므로 자동으로 다시 보정합니다.

### 설정 (⚙️)

- **응시 유지 시간**: 처음에는 1000ms 권장, 익숙해지면 500~700ms로
- **칸 전환 속도**: 하이라이트가 위/아래 칸에 머무는 시간 (처음에는 2초 안팎 권장)
- **사용할 눈**: 한쪽 눈꺼풀 처짐이 있으면 반대쪽 눈만 사용
- **말 속도**, 계속 응시로 취소 켜기/끄기
- **학습 데이터 내보내기/가져오기**: 환자가 자주 쓰는 단어 학습 내용을 JSON으로 백업하세요.
  브라우저 데이터를 지우면 학습 내용이 사라집니다.

## 개발

```bash
npm test   # 한글 오토마타 / 예측 엔진 / 스캐너 / 보정 계산 단위 테스트
```

| 파일 | 역할 |
| --- | --- |
| `js/hangul.js` | 한글 자모 조합 오토마타 (유니코드 U+AC00 조합 수식) |
| `js/scanner.js` | 빈도 가중 이분 트리 + 선택 사이클 |
| `js/predictor.js` | 로컬 통계 언어 모델 (트라이·바이그램·조사 규칙·사용자 학습) |
| `js/eye-tracker.js` | 시선 감지 (특징 추출·보정·융합·체류 상태기계·깜빡임 게이팅) |
| `js/tts.js` | 한국어 음성 합성 |
| `js/main.js` | 화면 전환·선택 사이클·이벤트 배선 |
| `data/` | 자모 빈도표, 어휘 사전, 빠른 말 |

## 제한 사항

- 브라우저에 한국어 TTS 음성이 없으면 문장이 화면에만 표시됩니다
  (Windows: 한국어 음성 설치, macOS: 유나(Yuna) 설치 후 사용)
- 최초 실행 한 번은 모델 다운로드를 위해 인터넷이 필요합니다
- 의료기기가 아니며, 응급 상황 의사전달의 유일한 수단으로 사용해서는 안 됩니다
