# 👆 손끝으로 (with-eyes)

**화면의 큰 두 칸을 눌러 고르는 것만으로 한국어 문장을 만들고 음성으로 말하는 의사소통(AAC) 웹앱**

정밀한 조작이 어려운 분을 위해 화면을 **위/아래 두 개의 큰 버튼**으로만 나눴습니다.
원하는 글자가 있는 칸을 누르면 선택지가 절반으로 줄어들고, 몇 번만 누르면 글자가 입력됩니다.
단어 추천, 빠른 말(긴급 문장), 음성 합성까지 **모든 처리가 사용자의 기기 안에서만** 이루어지며,
서버로 어떤 데이터도 전송하지 않습니다.

> 이 저장소는 원래 시선 추적(눈동자) 기반으로 시작했습니다("눈으로").
> 실사용 테스트 후 터치 방식으로 전환했으며, 시선 추적 버전은 git 히스토리에 남아 있습니다.

## 사용 방법

- 화면이 **위 칸**(추천 단어·명령)과 **아래 칸**(자모판)으로 나뉘어 있습니다
- **원하는 글자·단어가 있는 칸을 누르면** 그 칸의 절반만 남습니다. 반복해서 하나가 남으면 입력
- **⌫ 삭제 버튼**: 고르는 도중이면 한 단계 뒤로, 메뉴에서는 취소, 다 고른 뒤에는 마지막 입력 지우기
- 단어를 몇 글자 입력하면 위 칸에 **추천 단어**가 떠서 한 번에 완성할 수 있습니다
- **⚡ 빠른 말**: 아파요 · 화장실 가고 싶어요 · 물 주세요 같은 긴급 문장을 몇 번의 터치로 바로 발화
- **🔊 말하기**를 고르면 문장을 소리 내어 읽어줍니다

## 작동 방식

| 단계 | 기술 |
| --- | --- |
| 글자 선택 | 한글 빈도 가중치 이분 트리 — 자주 쓰는 글자일수록 적은 터치로 도달 (평균 3~4회) |
| 한글 조합 | 2벌식 IME 방식 자모 오토마타 (겹모음·겹받침·연음 분리·자모 단위 지우기) |
| 단어 추천 | 완전 로컬 통계 언어 모델 — 자모 접두사 트라이 + 빈도 사전 + **사용자 어휘/연쇄 학습**(localStorage) + 받침 규칙 기반 조사 추천 |
| 음성 출력 | Web Speech API 한국어 음성 (기기 내장 음성 우선) |

## 실행 방법

빌드 과정이 없는 정적 웹앱입니다.

### 모바일 / 다른 기기에서 (GitHub Pages)

푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다:

**https://choisian.github.io/with-eyes/**

휴대폰/태블릿 브라우저로 접속하면 바로 사용할 수 있습니다. 카메라·마이크 권한이 필요 없고,
사용 중에는 화면이 꺼지지 않습니다. 데스크톱에서는 ↑/↓/Backspace 키로도 조작됩니다.

### 로컬에서

```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 설정 (⚙️)

- **말 속도** 조절
- **학습 데이터 내보내기/가져오기**: 자주 쓰는 단어 학습 내용을 JSON으로 백업하세요.
  브라우저 데이터를 지우면 학습 내용이 사라집니다.

## 개발

```bash
npm test   # 한글 오토마타 / 예측 엔진 / 선택 트리 단위 테스트
```

| 파일 | 역할 |
| --- | --- |
| `js/hangul.js` | 한글 자모 조합 오토마타 (유니코드 U+AC00 조합 수식) |
| `js/scanner.js` | 빈도 가중 이분 트리 + 선택 사이클 |
| `js/predictor.js` | 로컬 통계 언어 모델 (트라이·바이그램·조사 규칙·사용자 학습) |
| `js/tts.js` | 한국어 음성 합성 |
| `js/main.js` | 화면·터치 입력·선택 흐름 |
| `data/` | 자모 빈도표, 어휘 사전(516 단어), 빠른 말 |

## 제한 사항

- 브라우저에 한국어 TTS 음성이 없으면 문장이 화면에만 표시됩니다
  (Windows: 한국어 음성 설치, macOS: 유나(Yuna) 설치 후 사용)
- 의료기기가 아니며, 응급 상황 의사전달의 유일한 수단으로 사용해서는 안 됩니다
